¿Cómo funciona DOGO?

Nuestro sistema busca entregar una recomendación personalizada según las características de cada perro.

🐶

1. Conocemos al perro

Registramos información como su edad, tamaño y nivel de energía.

2. Analizamos sus necesidades

El Quiz considera las características entregadas por el dueño.

3. Recomendamos un plan

DOGO entrega una recomendación de servicio pensada para las necesidades del perro.
